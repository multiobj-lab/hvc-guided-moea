# HVC-Guided MOEA

This repository provides supporting resources for a study on HVC-guided many-objective evolutionary optimization, including the implementation of HVC-RankNet and links to the original implementations of two reference neural models used in related comparisons.

## Repository Contents

### Model Implementations

| Folder | Description |
| --- | --- |
| `hvc_ranknet_code/` | Contains the PyTorch implementation of HVC-RankNet. |
| `hv_net_code/` | Contains a link to the original HV-Net repository. |
| `set_transformer_code/` | Contains a link to the original Set Transformer repository. |

### Additional Files

| File | Description |
| --- | --- |
| `stk_dominatedhv.rar` | Archive containing the STK-related hypervolume utility used in the experiments. |
| `requirements.txt` | Python dependency list. |

## Basic Usage

1. Install the Python dependencies listed in `requirements.txt` when needed.
2. Use `hvc_ranknet_code/` for the HVC-RankNet implementation.
3. Follow the links in `hv_net_code/` and `set_transformer_code/` to obtain the reference model implementations.
